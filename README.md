Drishti360 – Smart Inspection & Monitoring System
📌 Project Overview

Drishti360 is a MERN-based Smart Inspection & Monitoring System designed to provide a centralized platform for monitoring NGO-funded projects, field inspections, project verification, risk alerts, CCTV monitoring, analytics, video verification, and reporting.

The system provides a centralized dashboard for administrators to monitor NGO projects, track inspections, verify project activities, identify potential risks, and generate structured reports.

The platform aims to improve transparency, monitoring efficiency, accountability, and data-driven decision-making in NGO project management.

🎯 Objectives

The major objectives of Drishti360 are:

Digitize the NGO project inspection process.
Centralize NGO and project information.
Track field inspections and verification.
Monitor project progress and funding.
Provide CCTV-based project monitoring.
Identify and track project risks.
Provide geographic project visualization.
Support video-based verification.
Generate comprehensive project reports.
Provide analytics for administrative decision-making.
Maintain structured monitoring and verification records.
